# CYBERSTEEL — Собери технологию

MVP игры с тремя производственными маршрутами и одиннадцатью карточками в каждом.

## Поведение

- Сначала выбор: трубы для АЭС, общего назначения более 20 мм или для авиации.
- Первая карточка — вводная заготовка — закреплена. Все остальные десять, включая заключительный контроль, перемешиваются.
- Перестановка перетаскиванием за ручку, выбором двух карточек или стрелками клавиатуры. Home/End перемещают к началу/концу подвижной части.
- На каждой карточке есть «?». Нативное модальное окно содержит демонстрационный текст; закрывается кнопкой, Escape или нажатием на фон. Порядковые номера из источника в подсказках не раскрываются.
- Проверка сравнивает типы операций, а не скрытые идентификаторы повторяющихся экземпляров. Одинаковые карточки взаимозаменяемы.
- После перестановки устаревшие результаты проверки сбрасываются. После успеха доступны повторный запуск и выбор другой трубы.
- Нет авторизации внутри игры, серверной базы, сбора данных, аналитики и сохранения результатов между перезагрузками.

## Содержание

Маршруты согласованы в переписке и находятся в `app/production.ts`. Выбранные операции сохраняют все явные вхождения из схемы, включая подпункты 1.x. Дополнительные проходы повторяемых циклов не разворачиваются. Стартовая заготовка — вводная карточка состояния, не дополнительная технологическая операция. Тексты для поп-апов — намеренные заглушки MVP, не технологическая инструкция.

- https://cybersteel.com/technologies/long-tubes-for-nuclear-power-stations/
- https://cybersteel.com/technologies/truby-obshchego-naznacheniya-bolee-20mm/
- https://cybersteel.com/technologies/tubes-for-aviation/

Перед выставочным или публичным применением требуется согласовать содержание и использование бренда/фотографии с CYBERSTEEL.

## Запуск и проверки

`npm install` и `npm run dev`.

`npm test` — согласованные маршруты, 1500 перемешиваний, сохранение первой карточки и состава колоды, взаимозаменяемость повторов, перемещение финальной карточки, неверный ответ, исправление, успех и перезапуск.

`npm run typecheck`, `npm run lint`, `npm run build`.

`app/game.ts` — чистая модель игры. `app/page.tsx` — интерфейс, указатель/клавиатура и модальное окно. `app/globals.css` и `app/game.css` — стили, включая мобильные размеры и уменьшение движения.
